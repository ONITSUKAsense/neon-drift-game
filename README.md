# NEON DRIFT · 霓虹夜驰

一局「许愿式编程」做出来的伪 3D 霓虹赛车：夜空、条纹落日、无限弯道、车流擦身、护盾与氮气。
纯手写 Canvas 2D，**零依赖**，单文件 122 KB，双击即玩。

## 在线试玩（手机 / 微信可直接打开）

👉 **https://onitsukasense.github.io/neon-drift-game/**

- 手机上建议 **横屏**，按住屏幕 **左 / 右半边** 转向；
- 微信里直接点链接即可，不需要下载文件。

## 直接开玩（本地）

- **单文件版**（推荐，离线可用）：双击 `dist/neon-drift.html`
- 开发版（改代码用，需要本地服务器）：
  ```bash
  python -m http.server 8777
  # 浏览器打开 http://127.0.0.1:8777/
  ```

## 操作

| 按键 | 作用 |
| --- | --- |
| `←` `→` / `A` `D` | 转向 |
| `↑` / `W` | 全油门（默认自动巡航到 76% 速度） |
| `↓` / `S` | 刹车 |
| `Shift` | 氮气加速（消耗 NITRO 槽） |
| `Space` | 漂移（转向更利，但会被离心力甩得更开） |
| `P` / `Esc` | 暂停 / 继续 |
| `M` | 静音 |
| `Enter` | 开始 / 重开 |

触屏：按住屏幕左半边左转、右半边右转。

## 玩法

- **擦身而过**：和车流保持 0.2–0.5 个车道宽的距离通过，加分并把倍率往上堆（最高 9×），还能回充氮气。
- **撞车**：扣一格护盾（共 3 格），速度掉到 34%，倍率清零；护盾归零即结束。
- **能量球**：吃掉补氮气、加一点倍率。
- **漂移**：按住空格并高速行驶会持续加分，但弯道里更难控。
- 最高分与最远距离存在 `localStorage`，结束页有分段评价。

## 技术要点

- **伪 3D 路面**：赛道切成 200 单位的片段，每段带 `curve`（横向弯曲量）和 `y`（山丘高度）。
  每帧用 `cameraDepth / cameraZ` 把片段两端投影成梯形，从近到远铺满屏幕；`x` 逐段累加 `curve` 就得到了弯道，`y` 累加就得到起伏。
- **立体物单独后画**：路面先画完，再把车/路障/路灯按 z 从远到近画上去。
  （如果按路段边走边画，高一点的 sprite 上半身会被更远的路段盖掉——这坑踩过。）
- **零素材**：落日、山脉、车、能量球、路肩霓虹全部是 Canvas 路径 + 渐变，没有一张图。
- **声音**：WebAudio 现场合成——引擎三个振荡器随速度变调，低音琶音 + 底鼓，撞车/擦身是滤波噪声。
- 60 fps @ 1264×625（Chrome，headless 实测）。
